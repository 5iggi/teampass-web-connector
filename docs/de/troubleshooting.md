# Fehlerbehebung

**Menü:** [Start](README.md) · [Installation](installation.md) · [Anwendung](user-guide.md) · [Erstellen](build.md) · [Technik](technical.md) · [Sicherheit](security.md) · [Fehlerbehebung](troubleshooting.md) · [English](../en/README.md)

---

| Problem | Prüfung |
|---|---|
| Keine Verbindung | Basis-URL, HTTPS-Zertifikat, API-Freigabe, Benutzerrechte und Proxy prüfen. |
| Keine Treffer | URL-Abgleich wechseln, Ordnerrechte prüfen, „Alle“ testen. |
| Felder werden nicht gefüllt | Zielseite neu laden, Feldregeln prüfen, bei iframes/Shadow DOM manuell testen. |
| Tresor bleibt gesperrt | Passphrase erneut eingeben; bei Verlust ist keine Wiederherstellung vorgesehen. |
| Nach Update auffällig | Erweiterung neu laden, Einstellungen exportieren, Browserkonsole ohne Geheimnisse prüfen. |

Für einen Issue Browser/Version, Extension 1.0.0, TeamPass-Version, reproduzierbare Schritte und bereinigte Konsolenmeldungen angeben.
