## Grundsätze
- TeamPass ausschließlich über vertrauenswürdiges HTTPS betreiben.
- Dediziertes Konto mit minimalen Leserechten verwenden.
- Lokalen Tresor und kurze automatische Sperrzeit aktivieren.
- Browserprofil und Betriebssystem sperren, gemeinsam genutzte Profile vermeiden.
- Erweiterungen nur aus kontrollierten Builds oder signierten Stores installieren.

## Lokale Daten
Einstellungen liegen im Browser-Extension-Speicher. Geheimnisse werden nur entsprechend der implementierten Tresorlogik lokal verarbeitet. Ein entsperrter Browser, kompromittiertes Endgerät oder bösartige Erweiterungen bleiben ein Risiko.

## Meldung von Schwachstellen
Keine Sicherheitsdetails in öffentlichen Issues. GitHub Security Advisories verwenden und Protokolle vorher von Tokens, Kennwörtern, Cookies, internen URLs und personenbezogenen Daten bereinigen. Siehe `SECURITY.md`.
