Die Browser-Erweiterung verbindet Webseiten mit einer selbst gehosteten TeamPass-Instanz. Sie sucht passende Einträge, füllt Anmeldedaten, unterstützt das Speichern erkannter Zugangsdaten und schützt lokale Geheimnisse mit einem sperrbaren Tresor.

## Einstieg
1. [Erweiterung installieren](installation.md)
2. TeamPass-URL und API-Zugang in den Einstellungen hinterlegen.
3. Verbindung testen und lokalen Tresor aktivieren.
4. Eine Anmeldeseite öffnen, Erweiterung anklicken und Eintrag auswählen.
