## Principles
- Serve TeamPass only over trusted HTTPS.
- Use a dedicated account with least-privilege read access.
- Enable the local vault and a short automatic lock timeout.
- Lock the OS and browser profile; avoid shared profiles.
- Install only controlled builds or signed store packages.

## Local data
Settings live in browser extension storage. Secrets are handled locally according to the implemented vault logic. An unlocked browser, compromised device, or malicious extension remains a risk.

## Vulnerability reporting
Do not publish security details in public issues. Use GitHub Security Advisories and remove tokens, passwords, cookies, internal URLs, and personal data from logs. See `SECURITY.md`.
