## Main features
- Find TeamPass entries matching the current website.
- Filter results and display all accessible entries.
- Fill usernames and passwords into detected fields.
- Save detected credentials as a new item.
- Optionally submit forms after selection.
- Configure URL matching, field policies, and folder access.
- Support HTTP network authentication where browser and target permit it.
- Lock, unlock, and automatically lock the local vault.

## Recommended workflow
1. Open the target site.
2. Open the toolbar icon.
3. Unlock the local vault if required.
4. Verify the results and select the intended entry.
5. Check URL, username, and destination before submitting.

## Saving new credentials
Open the save dialog after a detected sign-in and verify folder, label, username, and URL. Never store production credentials in a test folder or under the wrong site.

## Limitations
Complex SPAs, Shadow DOM, multi-step sign-in, CAPTCHA, passkeys, and vendor-specific forms may require custom field rules. The extension does not bypass MFA, CAPTCHA, or browser security controls.
