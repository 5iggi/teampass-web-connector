The browser extension connects websites to a self-hosted TeamPass instance. It finds matching entries, fills credentials, can save detected credentials, and protects local secrets with a lockable vault.

## Getting started
1. [Install the extension](installation.md).
2. Configure the TeamPass URL and API access in Settings.
3. Test the connection and enable the local vault.
4. Open a sign-in page, select the extension, and choose an entry.
