---

| Problem | Check |
|---|---|
| Cannot connect | Verify base URL, HTTPS certificate, API enablement, user permissions, and proxy. |
| No results | Change URL matching, verify folder permissions, and try “All”. |
| Fields are not filled | Reload the page, review field rules, and test iframe/Shadow DOM cases manually. |
| Vault remains locked | Re-enter the passphrase; lost passphrases are not recoverable. |
| Issue after update | Reload the extension, export settings, and inspect sanitized browser-console output. |

For an issue, include browser/version, extension 1.0.0, TeamPass version, reproducible steps, and sanitized console messages.
