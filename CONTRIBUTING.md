# Contributing

Thank you for contributing. Keep changes focused, update both German and English documentation, and add or update tests.

1. Fork the repository and create a feature branch.
2. Run `python3 build.py --check`.
3. Test the unpacked extension in Chromium/Edge and Firefox.
4. Open a pull request with purpose, test evidence, and security/privacy impact.

Use clear commits. Do not commit credentials, generated packages, local configuration, or TeamPass data. By contributing, you agree that your contribution is licensed under MPL-2.0.
